# 第十六轮需求与回归映射

本页是源码与测试断言的定位表，不是额外一次执行报告。新增测试与保留的历史测试均列出；是否在最终固定源码通过，以本轮冻结清单及实际 Python / 浏览器日志为准。定向、重复执行、全量 Python、浏览器组分别报告，不能相加成“唯一用例数”。映射整理没有再次运行全套；独立复核触发的认证最小修复及定向验证另列。

工程层次：**生产链夹具**指真实 Store / Service / Agent / ModelClient / SQLite / API 代码配受控时间、行情或模型 HTTP 响应；**本机传输**指真正 TCP/TLS/CONNECT 与受控响应；**浏览器**指真实前端和临时后端。三者都不自动证明真实第三方供应商的传输成功、报告实质质量、真实正式生成、自然到期效果或长期连续运行。第十五轮旧 helper 的单任务 guard 回归仍保留，但不能用于声称本轮多任务连续运行通过。
