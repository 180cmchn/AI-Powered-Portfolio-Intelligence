# 第十轮：公开资料可达性与研究交付

本轮保留全部模型绑定及思考强度，不增加调用/时限预算，不改日常数据库或系统 DNS/代理。实际收费研究及原报告评审另见第十轮总交付；本页记录数据路径与工程验证，不把这些公开请求称作模型研究结果。

## 现场证据与修复

2026-10-30 17:30—17:31（Asia/Shanghai）的[公开端点诊断](tenth-public-data-diagnostic.json)再次观察到上交所、巨潮、东方财富 PDF 和鹏华域名由本机返回 `198.18.0.0/15`。这是基准测试/代理虚拟地址，不能作为可连接公网 IP；本证据不能指认具体软件是唯一原因。

17:44 的[当前Mac网络环境只读记录](tenth-mac-network-context.json)同时观察到 HTTP/HTTPS/SOCKS 及自动代理开关启用、环境代理存在、多个 utun 接口；仅记录开关和接口名，不导出代理地址或凭据。它们支持网络适配路径影响的诊断，不证明某个软件有错误。

原文适配器现在仅在**整个系统解析结果均为该虚拟地址段**、且输入是域名时，尝试一次有时限和响应大小上限的公开 DNS-over-HTTPS 查询。固定 HTTPS DNS 端点为 Cloudflare `1.1.1.1/dns-query`，只发送所请求的公开域名，无模型凭据。DNS 服务是解析基础设施，不是内容来源白名单。返回地址仍必须全部是公网；TCP 固定连接验证后的 IP，同时校验原始主机名的 TLS/SNI，每个重定向重新校验。回环、私网、链路本地、混合私网答案、IP 字面量均不进入备用解析。没有关闭 SSRF/TLS，也没有连接 `198.18.*`。

应用中的失败结果保留 `failure_stage`、`error_kind`、`next_action`，成功备用解析保留 `network_diagnostics`。这次三份真实公开 PDF 均成功下载并提取**第一页**：上交所 562500 2026-10-27 披露（14页、返回142字符）、东方财富公开文档（17页、190字符）、巨潮公开文档（16页、174字符）。均标为 `excerpt`，不是已读全文。文档 SHA256 与真实返回范围在诊断 JSON 中。

随后对同三份 URL 运行[原系统解析路径对照](tenth-public-data-control.json)，关闭本次命令的备用解析选项（未改任何系统设置），三项均在 `address_validation/non_public_dns` 阶段失败、正文0字符。该对照与上面的成功读取均在当前 Mac；不把独立开发助手的搜索结果混作应用下载。

日线原接口仍会间歇出现 `RemoteProtocolError`。适配器在公开 Eastmoney **未复权日线**发生网络失败时，可有界获取腾讯公开端点的整段未复权日线；不拼接两个来源，不把 `qfqday`/`hfqday` 当 `day`，不将其他证券/指数替换原身份。基准 CSI300/SSE50/CSI500 也按明确指数代码取得同期间指数日线。Tencent 返回的成交额保持未知、成交量单位标为未独立确认，不用于跨源成交量或金额比较。

本次159278由原源取得39行；518880、688825、562500和CSI300由备用源各取得39行，均截至2026-10-30，区间2026-08-31—2026-10-30。这证明本次请求的可达性与实际返回，不承诺后续持续可达或数据源永不更正。

当两个来源均失败时，`ResearchTools` 会在公开原始材料中有界寻找：同证券/基准、日线、同未复权/指数口径、覆盖请求日期、7日以内且抓取时点晚于请求期末收盘的快照。仅复用原始结构化材料；私有账户提取、模型生成、复权历史、来源不匹配均不复用。保留原材料 ID/抓取时点，明确 `cache_stale` 和刷新失败，不把旧缓存说成刚取到的行情。缺失日期不补零，不以近似日期冒充确切日期。

同一任务内的 DNS 路径和市场端点网络故障会记忆：30秒内不重复等价失败，之后最多再做一次自动验证；成功缓存始终可用。多个 Agent 等待同一 HTTP 请求只计一次失败。记忆只属于本任务、最多128条，不是永久拒绝层；新任务/显式文档 `refresh` 可以重新验证。不同公开域名和不同实际数据源仍可访问。

## 材料和报告语义

新增原生来源、原文读取默认 `classification=unclassified`；保存 `source_type` 与 `classification_origin`，和 `source_link/search_excerpt/excerpt/full_text/structured_data/failed` 访问范围分开。模型自行提取标 `model_extraction`，显式传闻分类原值保留。历史 `uncertain` 不批量改成事实或传闻。失败的 PDF 检索不再被包装成成功 `pdf_search`。

默认主 Agent 提示要求首屏回答研究对象、时点、建议和条件；已知账户风险可以交付，未知成本不阻止方向与集中度研究；未知项说明影响哪部分判断，不把资料不全当成万能拒绝。新增内置提示升级仅匹配第九轮或本轮初版的精确内置摘要，保留自定义提示、所有模型/强度绑定、历史冻结团队。

主/子启动事件记录单请求、子任务、整轮时限和总调用预算；超时区分 `child_deadline` 与 `analysis_deadline`，保留计算和已完成报告。本轮最终结果提供 `research_delivery`，分开报告已提交、专题完成/未完成及保存报告数；这些字段不声称资料齐全或预测准确。原有有界汇总恢复、最终计算摘要、SSE终止检查和原子发布保留。

真实试验又定位并修复了两处恢复问题：主Agent中途模型失败/整轮取消时，仅在完整工具轮次且已有成功计算或完整子报告的情况下保存有限研究检查点；未终止SSE与隐藏推理不保存，旧更完整检查点不降级。仅未使用、所有版本无正文、未被引用或声明已读的原生链接标题变化，不再错误阻塞汇总；同一原文正文更正、材料版本变化、账户/行情/范围/批次guard仍严格检查。旧保存状态只读重算有效资格，不改旧失败记录。恢复报告保留原未完成专题，与本轮新专题计数分列。

## 可操作诊断

在项目目录运行（不会调用模型或修改设置）：

```sh
.venv/bin/python scripts/diagnose_research_network.py
.venv/bin/python scripts/diagnose_research_network.py --url 'https://公开域名/实际文档.pdf' --symbol SZ:159278 --benchmark CSI300 --output /tmp/guanlan-public-network.json
```

默认只检查四个公开域名的系统 DNS；传 `--url` 才读取该文档第一页，传 `--symbol/--benchmark` 才获取最近60个自然日的日线。输出不包含账户数据库或模型 Key。`--no-public-dns-fallback` 可对照只用原系统解析路径，仍不会修改系统配置。

按实际失败阶段处理：

- `system_dns/dns`：看是否为虚拟地址、备用 HTTPS DNS 是否成功。备用失败时可先读取同一披露的其他公开发布域名；如需改用户网络工具的 DNS 模式/规则，由用户确认具体规则和回滚，本轮未改。
- `connection/download`：域名已解析但连接/下载失败，保留具体异常类型与时限；可以选择同份公开文本页或附件，不连续重复同一路径。
- `http`：403/401 是访问控制，429 是限流；不绕过授权，稍后或换合法公开发布地址。
- `content_type/extraction`：已收到网页或文档，但不是预期 PDF、所选页无文字或解析失败；使用返回的公开附件链接、其他页或文本版。扫描件不声称已 OCR。
- 行情：`source/fallback_from/primary_failure` 显示实际采用来源；`cache_reused_after_failure/cache_fetched_at` 显示原始缓存时点；无数据仍为缺口。
