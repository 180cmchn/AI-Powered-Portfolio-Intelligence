# 第六轮：供应商与统一角色实现

## 数据与权限

`model_providers` 只存连接、修订及安全凭据引用。表单/API 只接受 `api_key`、`base_url`、`protocol`，不接受默认模型、effort、显示名、模型列表地址或环境变量名。程序生成显示标识与 ID。模型的身份始终是 `(provider_id, model_id)`。

`agent_definitions` 是所有账户共享的目录：主 Agent、公告披露、市场价格、行业政策、ETF 指数、组合配置六个初始角色拥有各自职责和提示词。角色默认绑定单独保存。账户覆盖表只能包含供应商/模型成对覆盖及 effort；只写 effort 就继承默认的完整模型对。清除覆盖恢复默认，不能添加、删除或停用账户角色。全局自定义角色需要明确名称、职责和提示词；子角色不能获得 `finish_analysis` 等管理者权限。

任务快照冻结全局定义、提示词与工具版本、有效绑定、供应商连接修订、凭据引用修订。运行实例从该快照读取各自模型配置，Key 仅在必要的进程内存中使用。团队标识由有效角色定义、提示词/工具版本、实际绑定、供应商连接及凭据修订产生；发现时间、缓存错误、继承标签、账户 ID 不改变团队标识。历史版本信息仍完整保存在快照中。

## 自动目录发现

模型目录通过后端 `GET <API_BASE>/models` 读取；保留用户 API 前缀，规范化已粘贴的 `/responses` 或 `/chat/completions` 末尾，使目录和推理使用同一个 API 根路径。支持标准 `data[].id`、明确的 `models[].id/slug` 及单层 `success: true, data: {...}`。标准结构优先，不猜测任意字符串为模型。

目录使用一小时 TTL，同连接同修订的并发请求合并。单次最多读取五页、响应最多 2 MB、整次发现最多 45 秒；还有分页时保留游标并显示部分列表，使用继续加载接口取后续页。分页仅允许同来源的 models 路径；不跟随 HTTP 重定向、不把认证失败当作路径猜测机会，不向目录返回的任意主机发送 Key。

成功空列表、部分列表、认证失败、限流、不支持、超时、网络故障、格式错误分别保存。HTTP 200 HTML 不是空列表。暂时失败保留此前缓存；连接或凭据改变后，新修订不继承旧目录的选择资格。迟到旧请求不能覆盖新修订。完整列表中消失的已有模型保留绑定并显示需确认；部分页不能证明模型已消失。新选择由后端核对确实来自当前连接修订的目录，输入文本不能创建未发现模型。

## 凭据与换机

新 Key 通过 macOS `Security.framework` 存入用户钥匙串，使用 `ctypes` 调用系统 API，避免将 Key 放在命令行参数。SQLite 只含钥匙串引用、修订及不可逆标识。普通 GET 不回传完整 Key 或安全存储内部引用；错误不回显供应商正文。目录故意反射 Key 为模型 ID/分页游标时会拒绝该响应，反射到可选元数据时会脱敏。

安全存储失败会返回状态和修复提示，不使用明文文件、浏览器存储或把加密密钥放在同一个数据库中的替代方案。受限进程可能无钥匙串授权；通过正常 Mac 本地启动方式并允许系统钥匙串访问后重试。

留空 Key 保留现有凭据；掩码不允许当作新 Key。替换生成独立凭据修订，已运行的冻结任务仍使用旧引用，不会悄悄切换。显式清除会撤销该供应商的全部旧引用，后续请求边界检查拒绝继续使用；已在途的 HTTP 请求无法召回。轮换不会删除旧任务与预测归属。归档供应商/角色保留历史引用，只影响新任务的可用配置。

数据库备份不包含可直接恢复的 Key。换机后在供应商页面重新输入凭据，并刷新目录、确认角色绑定。旧环境变量 Key 仅通过内部兼容引用迁移；旧模型名成为角色历史绑定并标记 `legacy_unverified`，不会冒充自动发现结果。旧环境变量在任务运行/恢复时改变会使旧冻结引用明确失败，不能悄悄切换 Key。历史非法 effort 原样保留并显示配置错误，只有用户明确修改后才生效。

## 验证范围

`tests/test_sixth_config.py` 使用明确标注的 HTTP 与内存凭据替身验证真实生产组件；它不是上游模型能力证明。覆盖三字段限制、凭据不回显、URL 前缀、模型目录错误/分页/缓存/迟到响应、同名跨供应商、角色共享/覆盖/全局归档、快照与团队标识、两协议模型请求的原始 ID/凭据/effort 及服务器回报审计。

在本机使用合成临时凭据实际运行 macOS 钥匙串写入、读取相等检查和删除，成功；未使用或修改用户已有凭据。沙盒内调用返回安全存储授权错误，受批准的沙盒外同一代码完成回环。该结果只证明此机系统凭据存储路径，不证明真实供应商可访问。

五档 effort 原样发送；目录发现不证明模型额度、工具调用、联网或具体 effort 支持。此次保持已有 Responses 原生联网适配，不增加 Chat Completions 原生搜索，也不替换被服务拒绝的模型或强度。
