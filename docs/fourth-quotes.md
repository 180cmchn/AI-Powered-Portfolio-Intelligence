## 实现

`MarketProvider` 最多尝试两次主源暂时性连接失败、超时及 5xx，短退避；身份、解析、4xx 错误不重试，429 不立即重试，也不转备用接口。显式启用新浪备用源时，主源暂时性失败后仅请求一次新浪，最多 8 秒；整个报价调用包含所有备用路径硬封顶 45 秒。每次请求保存阶段、域名、次数、耗时、HTTP 状态（实际取得时）和异常类别，不保存请求头、凭据、响应错误正文或代理地址。

新浪适配仅支持已核实格式的沪深证券，通过 GB18030 解码后匹配请求证券的完整变量名，严格检查价格与日期、时间；不执行返回的 JavaScript、不复制网页把零价改成昨收的显示行为。报价保留源小数，涨跌幅注明由源现价与昨收计算。用户关闭备用源后不会联系新浪，也不需要模型或第三方搜索密钥。[新浪官方主页](https://finance.sina.com.cn/)说明其公开行情来自合作方，供获取信息使用，并提示错误、缺漏和延迟；这不是开发者 API 合同、再分发许可或 SLA。定位为小规模本地个人研究展示，不能承诺持续可用或交易级行情。

同一适配器实例短缓存让报价与证券身份读取复用响应，保留原 `fetched_at` 与来源时间。服务原有持久缓存仍负责跨刷新恢复：失败后的旧报价保留为 `error_cached`，不能获得新鲜状态。

主源与已启用的备用源均不可用时，只有已覆盖的交易日历确认休市且最近已完成交易日明确，才允许读取东财的未复权日线 `close`。要求证券身份匹配、日期正好等于该交易日，且价格有效。日线源时间如实为 `YYYY-MM-DD`，`as_of_precision=date`，`delay_seconds=null`。`session_close_at` 是单独标识的日历推导时间，不冒充供应商时间。状态为 `closed` / `last_close`，`fresh_for_triggers=false`。盘中或日历覆盖未知时不采用日线回退；到了下一交易日，缓存收盘报价重新评估为陈旧。

原始单价接口的真实源时间仍保留。最近已完成交易日的收盘后快照也标为 `closed`，不会误称正在更新的盘中数据。不存在有效价格、来源时间未知或时间异常时保留真实状态。

文档采集同步接入应用维护的 `begin_material_observation`：实际 HTTP 开始前申请持久序号，所有读取范围与缓存保留原不透明标识；缓存和并发键按观察数据库与账户范围隔离。保存端从专用参数接收标识，网页和模型字段不能决定最新版本。
