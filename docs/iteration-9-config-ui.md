# 第九轮：配置连接与供应商页面

本记录只覆盖配置、凭据引用、供应商交互和相关回归。日常 8765 实例、启停身份与真实外部服务结果见本轮总验收及 Mac 运维文档；这里的协议替身结果不能证明用户供应商已经连通。

## 已确认的代码缺陷与修复

第八轮 `sixth.load()` 的供应商请求直接向外抛错；周期刷新捕获后统一设置全局连接错误。一个 `GET /api/providers` 404 因此会被显示为“本地服务连接中断”。供应商表单又没有普通草稿机制，而每次 `render()` 都替换整个页面，所以周期重绘会丢失 Key、URL、焦点和光标。这条确定性链路已在真正的 FastAPI、临时 SQLite 和 Chromium 页面中复现、修复并回归。它说明此候选原因成立，不替代对用户当时浏览器请求及服务进程的现场证明。

现在健康状态与局部资源错误分开；HTTP 错误显示脱敏 method/path/status。集合路由缺失、对象不存在、连接失败、超时、返回格式异常分别处理。确定性缺路由 404/405 暂停该路由自动读取，用户“重新连接”或“重试当前页面”才解除。自动目录读取的局部失败按供应商和连接修订保存，成功仅清除对应目标的错误，旧响应不能覆盖新连接或清除另一供应商的失败；失败的自动发现等明确重试后继续。兼容标识缺失/不一致显示版本核对与安全重启提示，不把 404 解释成断网，也不伪造空列表。

当前供应商页面重绘保留正在编辑的真实 DOM 节点和光标。它不进入跨页面通用草稿表、localStorage 或 sessionStorage。离开当前页面、取消输入或关闭编辑对话框会释放输入；整页刷新有未提交 Key 时触发浏览器离开提示。保存失败不会伪装成功或静默清除输入；成功提交清除本次 Key，在请求途中另行编辑的新输入保留。

## 环境、持久连接和角色的优先关系

- `app/config.py` 仍用默认不覆盖策略加载项目 `.env`。已经存在的 shell 变量优先；管理器只把 dotenv 来源变量名传给子进程，诊断不把它们误报成用户 shell 配置。
- 新库沿原迁移连接识别合法 URL、Key 引用和协议。供应商页面对已识别、尚未抓取目录的环境连接自动发起一次目录读取；不调用付费模型，不随机选择列表第一项。Key 和 URL 已有但模型未选时显示“供应商已识别，主 Agent 待绑定模型”。
- 一次性迁移标记不再是恢复死角。`GET /api/environment-connection` 返回来源、Key 是否存在、目标 URL/协议、保存修订、差异和不透明预览标识；不返回 Key。网页明确确认目标后 `POST /api/environment-connection/import` 才幂等更新原环境连接或另建连接。
- `.env` 运行期间改动/移除会提示安全重启。不会在活动任务中全局 override，也不会从磁盘热替换已有任务的环境凭据。重启后先检测并导入连接，已有网页连接及全局/账户角色绑定不会被自动覆盖。
- 更换端点、协议或凭据会生成新连接修订并隔离目录/能力缓存。已明确撤销的迁移/环境连接不能通过重新读取 `.env` 复活；须由供应商表单明确录入新的凭据。
- 历史 `MODEL_NAME` 保留为待确认角色绑定。只有该 ID 出现在实际目录后才允许作为已确认配置使用；未出现时错误保留。界面仍没有手填模型 ID、供应商模型字段或 Profile。
- `configuration_readiness(account_id)` 根据所选账户有效覆盖给出连接是否保存、Key 引用状态、目录状态、主 Agent 绑定、各角色配置错误、函数和原生联网的独立状态。显示不会付费探测所有角色；一个子角色错误不使供应商页面离线。Chat 的原生搜索限制继续保留。

## 保存结果与秘密边界

供应商创建/编辑请求使用 `X-Operation-ID`。数据库在提交连接的同一事务登记操作 ID、供应商、修订和非敏感输入身份；操作摘要不含 Key 或由 Key 派生的值。相同操作 ID 返回其首次已提交连接，不重复写凭据。响应丢失或写请求返回可能发生于提交后的 HTTP 5xx 时，前端只查询 `GET /api/provider-operations/{id}` 核对结果，不自动重发 POST/PUT。

目录失败不回滚已经保存的连接，页面明确显示“连接保存成功，模型目录失败”，用户可单独刷新目录。目录只采用真实返回的模型 ID；401/404/429、失败和历史缓存继续有独立状态。Key 不写入 SQLite 原文、GET、通用草稿、浏览器持久存储或浏览器测试产物。浏览器回归关闭截图、trace 和请求正文记录；服务器凭据存储与目录是显式替身，真实 macOS 钥匙串验收另见总记录。

新增浏览器组使用真实 FastAPI 路由和临时 SQLite，明确的内存凭据及 HTTP 目录替身，覆盖：有效空供应商列表、慢输入跨后台轮询、选择/粘贴式输入、404 熔断与恢复、500、局部断连、延迟、焦点/光标、三字段创建/修改、目录认证失败、从真实替身目录绑定主/子角色并重开核对、保存响应丢失、双击不重复写入、GET/浏览器存储无 Key。脱敏结果输出 `test-results/ninth-browser.json`。新增 npm/CI 组保留既有三组浏览器测试。

测试不把协议替身当作真实上游能力证明；不证明所有浏览器扩展、外部密码管理器或用户过去的浏览器缓存状态。无模型绑定时基础页面与供应商入口可用，不等同具备研究或原生搜索能力。
