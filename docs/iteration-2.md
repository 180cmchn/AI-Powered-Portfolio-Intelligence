# 第二轮交付：持续研究与建议跟踪

基线是 `e62ee5e27c498e5359f31715ec8927d6ad1a414e`，检查时 `main` 工作区干净，原有 57 项测试通过。本轮在原有 FastAPI、SQLite、异步执行器、模型适配器和原生前端上迭代，没有接入券商或执行交易。

## 已实现的业务闭环

1. **调度与恢复**：`research_demands` 独立保存候选扫描、账户综合分析、事件增量分析、收盘复核需求。全局候选研究使用独立 `global_runs`，默认一次公共研究供各账户复用。运行中的账户研究不因周期或新闻被取消；未开始的需求合并，运行期间新增需求等待后续执行。需求记录保存分配任务及延迟/合并原因；持仓变更把未完成需求迁至最新版本。账户队列按创建时间公平领取，仍使用版本、最新任务 ID 和运行状态三重发布检查。
2. **材料访问**：`list_materials` 默认返回轻量索引，`get_material`、`read_material_range`、`search_materials` 按需读取。HTML 保留相对附件链接；PDF 有总页数、元数据、按物理页码读取、关键词位置及字符续读。完整响应字节 hash 与原文/页面范围保留，未读取的内容不会标成全文。会话上下文在完整工具协议边界归档，Agent 可按记录 ID 重新访问自己的历史。
3. **资讯更新**：同 URL、同发布时间也比较内容及完整下载字节指纹；更正追加不可变版本、上一版本 ID、变化位置和前后片段。旧版保留，恢复到更早文本也生成新版本。摘要、选页和原文是不同访问表示；转载保留自己的来源，不冒充独立佐证。资讯扫描默认 08:00–23:00 每 30 分钟，独立于交易时段，只有配置搜索词与搜索服务才调用。资讯版本与待通知记录同事务保存，发给所有相关研究需求后才确认通知完成。
4. **建议跟踪**：报告可附结构化建议，系统绑定账户、证券、输入版本和生成时间。状态为 `watching / triggered / needs_review / expired / revoked`。代码只计算明确的行情条件；定性条件和材料变化由 Agent 判断。只使用时间有效的报价触发。持仓/偏好变更需要重评；过期报告和建议不能继续标为当前有效。价格条件使用跨报告的语义指纹锁存，避免价格一直满足时无限重跑；离开区间后再次进入可以重新触发。无效或已经过期的报告日期最多为同一输入触发一次纠正研究。
5. **公共研究与账户适配**：市场、板块、候选研究记录保留入围原因、依据、首次发现、最近复核、状态及变化；公共记录无账户上下文，账户适配独立保存。新建议按证券替换旧建议，`revoked_suggestion_ids` 支持主 Agent 明确撤销；普通报告不会隐式撤销整个账户的跟踪建议。报告未说明的相关旧建议保留为待复核。新发现的候选建议自动加入行情监控，即使尚未加入用户股票池。
6. **数据能力与前端**：新增日 K / 可选分钟口径、板块目录与成分、返回页市场广度、板块与基准历史、利润表及可比同比计算。行情缓存跨账户复用，研究前网络等待有总时限。市场页自动更新并保留表单节点、草稿、焦点和光标；历史分页、报告按需缓存、事件游标、材料分段读取降低轮询负担。界面展示建议状态、公共研究和需求处理原因。

主 Agent 仍自主决定拆分、直接研究、派发、追问和结束。没有来源白名单、可信度阈值、独立审核 Agent、固定评分或上涨概率。

## 数据库与 API 兼容

首次打开 schema 1 数据库时，先用 SQLite 在线备份生成同目录 `<数据库名>.before-v2.bak`（权限 0600），再幂等创建附加表/索引、回填材料索引并升级为 schema 2。账户、历史报告、快照和已有材料 ID 不改变；没有删除旧表或清空用户数据。回填与版本更新在事务内完成，中断后可再次运行。高于当前支持版本的数据库拒绝打开。

`restore.py` 接受 schema 1 或 2，仍要求先停止服务；旧备份恢复后在启动时升级。自动备份不包含 `.env`。需要回退程序时，应先停服务，再恢复升级前备份；旧程序不应直接使用新增 schema。

原有主要账户 API 保留。列表新增 `limit/offset`；材料列表默认轻量索引，旧全文列表可显式传 `index=false`。任务列表默认不带全部事件/结果，可用 `events=true` 或单任务详情读取。新增：

- `/api/materials/{id}/range?start=0&length=8000`
- `/api/jobs/{id}/events?after=0&limit=100`
- `/api/analyses/{id}`、`/api/accounts/{id}/recommendations`
- `/api/research`、`/api/global-research`、`/api/demands`

`waiting_config` 启动恢复仅检查配置是否齐全，不承诺密钥已认证。补齐 `.env` 并重启后只恢复最新输入任务；已经被替代的任务不恢复。缺配置期间周期需求合并到等待任务，不每次创建新模型任务。保存设置也会恢复等待工作，不中断已运行的研究。

## 本机运行与配置

继续使用 `./start.command`、`./stop.command`；`--mode demo` 使用独立演示库。关闭网页不停止后台进程。修改 `.env` 后重启。页面保存的非密钥设置优先于环境默认值；模型名若曾在页面保存为空，需要在页面填写。详细命令见 [README](../README.md)。

新增设置在系统设置页可维护：资讯时间段/间隔、是否回读来源、报价复用时长、研究前报价总超时、文档缓存、研究数据源、Tushare token 的环境变量名。凭据值不发送至前端。

睡眠/网络中断后按当前数据合并错过的周期，保存合并窗口信息；已持久化的待执行需求保留。观察到跨日恢复时补发上次已观察交易日尚未分配的收盘复核，并注明当前访问时点。不会把离线期间每个历史窗口伪造为当时执行。默认两个账户任务与一个公共任务可并行；公共/账户任务都有总时限及中断恢复次数限制。

日历仍明确只覆盖 2026 年；跨年停止交易时段自动分析并展示未知原因，手动研究和配置的公开信息扫描可以继续。通过 `STOCK_CALENDAR_PATH` 指定已核实的新 JSON（`coverage`、`holidays`、`overrides` 格式沿用当前文件）。没有自动猜测未来休市日期。

## 验证、外部能力与剩余范围

最终 Python 回归 **131 项通过、0 失败**；实际测试命令、数量和分类见 [验证记录](verification.md)。真实联网时间、成功/失败及字段口径见 [数据源记录](providers.md)。完整交易时段确定性集成验证得到 **48 次全局候选扫描、4 个账户各 16 次综合分析需求**；忙碌、重启、资讯更正、期限、价格、旧结果迟到与账户变更都有回归。

真实读取已验证 110 页财报的第 28 页；公开历史、板块、成分和利润表最终适配器有真实成功响应，也出现过 `RemoteProtocolError`。这不是稳定性 SLA。Tushare 认证与权限、Tavily/Brave 认证均未实测。

真实模型评估入口已执行，但缺模型名/密钥而退出 **78 / SKIPPED**。十类评估输入、逐案审阅标准、模型输出/用量/失败记录均已实现；合成案例只是输入，绝不替代真实模型回答。真实模型事实分类、反证使用和账户推理质量仍待配置后验证。

明确剩余范围：无 OCR、完整三大财务报表库、历史板块成分、ETF 穿透、全市场自动股票池、真实券商/下单、收益验证或系统推送。分钟与复权路由已实现但样例未联网验收。文档下载缓存为有界进程内缓存，重启可能重新下载；SQLite 中已保存正文/版本仍在。退出或重启会从持久任务重新研究，不恢复模型的内存会话。Mac 系统睡眠未进行人为实机测试，仅验证时钟/持久恢复逻辑。
