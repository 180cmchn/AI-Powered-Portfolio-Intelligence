# 第十六轮复现入口

工程回归从项目目录运行，使用项目解释器，不加载个人 `.env`：

```sh
PYTHON_DOTENV_DISABLED=1 .venv/bin/python -m pytest -q
PYTHON_DOTENV_DISABLED=1 PYTHON="$PWD/.venv/bin/python" npm run test:browser
```

模型路线正常入口为 `start.command` / `scripts/manage.py start`，网页“设置 → 研究运行设置 → 模型连接路线”保存 `environment` 或 `direct`。只有显式保存才改变后续模型请求，在途任务保留自己的路线及修订。受控正常子进程回归位于 `tests/test_sixteenth_model_network.py`，包括配置保存、重启、目录、显式能力检测、真实worker模型HTTP、环境代理、NO_PROXY及TLS/环境CA；该回归不使用真实供应商、不代表供应商能力认证。

真实业务矩阵入口（输出目录必须不存在，替换参考账户ID；会使用项目供应商并产生付费调用）：

```sh
.venv/bin/python scripts/verify_sixteenth_live.py \
  --source data/live.sqlite3 \
  --reference-account '<现有参考账户ID>' \
  --output data/evaluations/sixteenth-normal-matrix-new \
  --route environment \
  --manager-effort xhigh \
  --run-real
```

这里的 environment 是第一轮真实矩阵选择；追加故障调查后，第二轮在新独立库显式使用 `--route direct`。两轮各自保存结果，选择direct不代表自动回放旧失败请求。不要为了追求成功率悄悄更换路线、回放已接受而结果未知的请求，或反复覆盖同一输出目录。每次新执行都保留独立身份和失败分母。参考库只读，只复制供应商/角色/配置；账户、100000元期初现金和成交由独立库正常API新建。经理原参考覆盖为 max，本轮按用户授权仅在独立库选择 xhigh，其余有效绑定、40次任务上限、限时和 null 输出上限保持。没有修改日常库或系统代理。

验证器允许合法多任务，声明已启动任务数阈值12及4小时观察边界，随后按正常worker处理。脚本每2秒观察，只有已启动数大于12或时间到界才停止，因此并发worker可能已开始第13项或同轮更多项；12不是发起前硬上限。到界经正常停服保留未处理任务，不把额外合法任务伪造为 failed；验证执行自身会记录 stopped_with_failure 及观察边界原因。模型请求沿用每任务既定调用上限、限时和原有HTTP重试策略。隔离配置另固定 max_job_attempts=1，限制进程中断后的执行恢复次数；它与 max_model_calls=40 的HTTP容量不同，也不代表逐字段保留日常所有恢复设置。输出记录实际完成的阶段、HTTP事件、当前报告/预测、原文文件和启停；若观察边界提前退出，重启验证可能尚未执行。`execution_result` 的持久发布判断与独立开发期内容复核分开；任何合法任务失败会保留为矩阵未全通过。

正式自然样本使用正常长期入口，并在“预测评估 → 账户固定批次设置”提前启用规则；默认15:30生成、18:00截止、1/5/20交易日期限、±0.5%震荡阈值。必须在真实交易日原窗口运行，前置核对证券身份、行情/日历和账户范围。页面可观察待基准、等待当前研究、已发布、弃权、未覆盖、错过截止等状态。已有研究未结束时保留正式批次原身份和原截止；不能通过延长窗口制造通过。本业务矩阵入口明确不启用独立账户的正式规则，即使在窗口内运行也不会自动验正式。本轮实际23:16启动时还已超过当日窗口，因此没有真实正式样本；正式验证需按上述正常长期入口提前启用。

模型研究暂停与到期评估开关独立；评分按原目标日期取历史行情，重复tick和重启保持逻辑样本唯一，数据更正保留修订。自然尚未到期就保留pending；不能把受控测试日期、历史行情或探索记录计入正式前瞻效果。Mac睡眠/关机不执行后台任务，未来结果需另行实际观察，本次不安排未来自动代跑。

日常服务部署遵循 [Mac操作手册](../mac-operations.md)：先核对目标PID/端口/路径/模式/版本和备份。本轮源码更新并未重启日常实例。私有原文/SQLite含模型配置引用和业务资料，公开复核使用本目录的脱敏身份、哈希与汇总。
